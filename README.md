-Fitlog

-Project Description

FitLog is a modern workout library and fitness tracking web application. It allows users to browse workouts, view detailed exercise information, add exercises to today's plan, save workouts for later, and track their daily fitness activities.

-Technology Used
Next.js
React
Tailwind CSS
DaisyUI
React Context API
React Hooks
React Toastify
JavaScript (ES6+)
Fitlog REST API

--Key Features
Workout Library — Browse all workouts in a responsive grid with workout images, muscle groups, equipment, difficulty, duration, calories, and rating.

Sort Workouts — Sort workouts by Duration, Calories, or Rating.

Detailed Workout Pages — View detailed information about each workout, including specifications, description, and step-by-step instructions.

Today's Plan & Saved Workouts — Add workouts to today's plan or save them for later.

Live Navbar Counters — Plan and Saved counters update automatically when workouts are added or removed.

My Plan Dashboard — Manage today's workouts and saved workouts from a dedicated dashboard with separate tabs.

Workout Management — Mark workouts as completed or remove them from the plan.

Toast Notifications — Get instant feedback when adding, saving, completing, or removing workouts.

Dynamic Routing — Each workout has its own dynamic route using Next.js App Router.

Loading State — Display a loading UI while workout data is being fetched.

Custom 404 Page — Show a user-friendly 404 page for unknown or invalid routes.

Active Navigation — Highlight the currently active navigation link using usePathname().

Global State Management — Manage and share plan and saved workout data across components using React Context API.

Responsive Design — Fully responsive UI for mobile, tablet, and desktop devices.
